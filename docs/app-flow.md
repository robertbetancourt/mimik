# Mimik — App Flow

## Goal

The entire experience should feel effortless.

Players should be able to launch the app and start playing in under one minute.

Every screen has a single purpose.

No unnecessary configuration.

---

---

# 1. Splash

Purpose

Introduce the game.

Duration

Approximately 2 seconds.

Content

• App icon
• Mimik greeting animation (future)
• App name

Automatically navigates to Home.

---

# 2. Home

Purpose

Start a new game.

Content

• Mimik
• Welcome headline
• Grid of category cards

Each category contains

• Illustration
• Title
• Short description

Selecting a category opens Game Setup.

---

# 3. Game Setup

Purpose

Configure the match.

Options

• Game Mode
• Number of Players
• Round Duration
• Number of Rounds

CTA

Start Game

---

# 4. Countdown

Purpose

Prepare the next player.

Sequence

3

2

1

GO!

Before GO, the phone verifies the correct orientation.

If the phone is not vertical, the countdown pauses until corrected.

---

# 5. Gameplay

Purpose

Guess as many words as possible.

Visible

• Current word
• Remaining time

Hidden

• Score
• Progress
• Future words

Tilt Right

Correct

Tilt Left

Pass

Every gesture briefly locks input to avoid accidental double detection.

Gameplay starts when the first word appears.

---

# 6. Turn Results

Purpose

Private feedback.

Displays

• Correct words
• Passed words
• Total score

Mimik reacts to the performance.

CTA

Next Player

---

# 7. Next Player

Purpose

Prepare the next participant.

Displays

"Now it's Alex's turn."

CTA

Continue

---

# 8. Final Results

Purpose

Celebrate the match.

Displays

• Ranking
• Winner
• Total points

Mimik celebrates the winner.

---

# 9. End Game

Options

Play Again

Change Category

Change Players

Return Home

End Match
