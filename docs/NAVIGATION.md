# NAVIGATION

## Principles

Simple.

Predictable.

No deep navigation.

Every screen has a clear purpose.

Players should never feel lost.

# Navigation Rules

Never interrupt gameplay.

Never show modal dialogs during a turn.

Avoid nested navigation.

Keep transitions simple and fast.
