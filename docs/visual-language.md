# VISUAL_LANGUAGE

## Visual Goal

Premium.

Warm.

Playful.

Editorial.

Friendly.

Expressive.

Timeless.

---

## Design Philosophy

The interface stays calm.

The illustrations create the fun.

Every screen should feel clean enough to let Mimik become the emotional focus.

---

## Experience

Players should feel:

- Welcome
- Comfortable
- Curious
- Excited
- Ready to play

Never overwhelmed.

Never distracted.

---

## Visual Style

- Warm light background
- Minimal interface
- Editorial composition
- Large whitespace
- Rounded components
- High-quality illustrations
- Soft color palette

---

## Color

Colors should feel:

- Warm
- Soft
- Cheerful

Avoid highly saturated interfaces.

Illustrations provide the strongest colors.

---

## Composition

Every screen should breathe.

Prioritize:

- Whitespace
- Clear hierarchy
- Large touch targets
- Comfortable spacing

Illustrations may break their containers to create depth and personality.

---

## Cards

Cards are small scenes.

Not simple containers.

Each category should tell a small visual story.

Some categories include Mimik.

Others use original illustrations built in the same visual language.

---

## Illustrations

Illustrations are the main source of personality.

Style:

- Rounded
- Friendly
- Expressive
- Dynamic
- Highly readable

Illustrations should feel collectible.

---

## Mimik

Mimik is never decoration.

Mimik appears only when it adds emotion.

Examples:

- Countdown
- Celebration
- Victory
- Funny failures
- Waiting states
- Turn summary

---

## Typography

Style:

- Modern
- Rounded
- Highly legible

Preferred families:

- Satoshi
- Sora
- Plus Jakarta Sans
- Urbanist

Typography should communicate clarity before personality.

---

## Components

- Minimal
- Rounded
- Lightweight
- Consistent

Avoid decorative UI.

---

## Motion

Every animation has a purpose.

Motion should:

- Celebrate
- Guide
- Reward
- Surprise

Never distract.

Never delay gameplay.

---

## Personality

The interface is elegant.

Mimik is expressive.

The contrast between both creates the product identity.

---

## Avoid

- Glassmorphism
- Heavy gradients
- Excessive shadows
- Visual noise
- Overdesigned layouts
- Decorative animations
- Generic game UI
- Overly childish aesthetics

---

## Inspiration

Editorial mobile apps.

Nintendo.

Duolingo.

Modern product design.

Premium illustration systems.

---

## Visual Rule

The interface should disappear.

The people should remember the game.

The game should remember Mimik.

---

## Character Usage

Mimik is not the interface.

Mimik is not every illustration.

Mimik appears intentionally.

The world should feel alive even when Mimik is absent.

Categories should tell stories through environments, objects and composition, not only through the mascot.
