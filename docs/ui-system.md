# UI_SYSTEM

## Principles

The interface should feel warm, playful and effortless.

Every element should be immediately understandable.

Content always comes before decoration.

Consistency is more important than novelty.

---

# Layout

Mobile first.

Safe area aware.

Generous whitespace.

Simple vertical hierarchy.

No visual clutter.

---

# Grid

Single-column layout.

Cards stacked vertically.

Consistent spacing throughout the app.

---

# Cards

Rounded corners.

Soft borders.

Very subtle shadows.

Warm surface colors.

Illustrations are the focal point.

---

# Buttons

Large touch targets.

Clear labels.

Single primary action per screen.

Secondary actions should never compete with the primary CTA.

---

# Typography

Friendly.

Highly legible.

Minimal font weights.

Clear visual hierarchy.

Avoid long paragraphs.

---

# Icons

Rounded style.

Simple silhouettes.

Consistent stroke weight.

Readable at small sizes.

---

# Color

Warm neutral background.

Bright accent colors.

High contrast for interactive elements.

Success and error colors should be instantly recognizable.

---

# Feedback

Every interaction provides feedback.

Visual feedback.

Haptic feedback.

Motion feedback.

Never rely on sound alone.

---

# Accessibility

Large tap targets.

High contrast.

Readable typography.

Support dynamic text where possible.

Color should never be the only way to communicate information.

---

# Philosophy

The interface should disappear.

Players should focus on playing, not on learning the UI.
