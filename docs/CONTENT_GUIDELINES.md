# CONTENT_GUIDELINES

## Tone

Friendly.

Playful.

Positive.

Clear.

Encouraging.

---

# Writing Style

Short sentences.

Simple vocabulary.

Natural language.

Avoid technical terms.

Avoid unnecessary explanations.

---

# Interface Text

Keep labels concise.

Prefer verbs over long descriptions.

One primary action per screen.

---

# Instructions

Players should understand the next step immediately.

Never require reading large blocks of text.

---

# Error Messages

Explain the problem.

Suggest the next action.

Remain positive.

---

# Mimik

Mimik never speaks directly.

Its personality is communicated through expressions and animations.

The interface text should remain neutral and easy to understand.
