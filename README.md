# Mimik

> A premium offline party game built with Expo and React Native.

Mimik is a local multiplayer charades game designed to bring friends and family together around a single phone.

Mimik is designed around a simple idea: great party games should be easy to start, easy to share and fun to play together. Everything runs locally on a single device, with no accounts or internet connection required.

Whether you're playing at home, on a road trip or during a family gathering, all you need is one phone and your imagination.

## 🎮 How to Play

1. Choose a category.
2. Configure the match.
3. Place the phone on your forehead.
4. Your friends act out the word.
5. Guess as many words as possible before time runs out.
6. Celebrate the winner!

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/robertbetancourt/mimik.git
```

Navigate to the project:

```bash
cd mimik
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npx expo start
```
